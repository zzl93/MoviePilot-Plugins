# PT 魔力计算器插件 - 代码说明

各 py 文件及主要方法/函数的功能简述。

---

## 插件入口

### `__init__.py`
插件主类与 API 入口，配置与做种、关联数据业务逻辑。

| 方法 | 功能 |
|------|------|
| `init_plugin` | 初始化 DB、配置、站点映射，同步配置中的关联 |
| `_api_form_options` | 配置页：站点、下载器、地址关键词选项 |
| `_api_downloader_tracker_options` | 按下载器返回 Tracker 地址选项 |
| `_on_site_refreshed` | 站点刷新事件：触发同步做种数据 |
| `_get_sites_to_query` | 按站点 ID/勾选站点查主项目站点列表 |
| `_get_sites_to_query_from_plugindata` | 仅从 plugindata 取站点列表（Page 用） |
| `_get_latest_userdata` | 按域名取最新用户数据 |
| `_get_bonus_seeding_data` | 做种数据：站点块 + 魔力计算，可拉下载器并写表 |
| `_api_bonus_data` | 做种与关联数据 API：未匹配列表、下载器候选等 |
| `_downloader_torrents_list` | 下载器种子列表（供配置等） |
| `_get_torrent_mappings` | 站点种子与下载器 hash 的关联映射 |
| `_save_torrent_mapping` | 保存一条站点种子与下载器种子关联 |
| `_remove_torrent_mapping` | 取消一条关联 |
| `_build_seed_association_payload` | 构建关联页 payload：未匹配、options、按站点下载器候选 |
| `_api_save_data` | 保存/删除关联 API |

---

## server 层

### `server/utils.py`
与业务无关的公共方法：Tracker 解析、魔力公式、配置解析、名称分词与匹配、显示宽度等。

| 方法 | 功能 |
|------|------|
| `parse_tracker_domain` | 从 tracker URL 解析出域名 |
| `tracker_full_host` | 取 tracker 完整主机名（小写） |
| `keyword_to_domain` | 配置关键词转统一域名 |
| `tracker_domain_group_key` | 从 tracker 取分组键，空则 `__no_tracker__` |
| `build_torrents_by_tracker_domain` | 下载器种子按 tracker 域名分组 |
| `parse_pubdate_weeks` | 发布时间字符串转距今周数 |
| `calc_bonus_per_hour` | NexusPHP 魔力公式，返回 (B, A, A/GB) |
| `parse_list_config` | 配置项解析：list 或逗号分隔字符串 |
| `torrent_key` | 由 torrent_id/name/size 生成唯一键 |
| `display_width` | 字符串显示宽度（中文=2，英文=1） |
| `truncate_by_display_width` | 按显示宽度截断字符串 |
| `tokenize_name_for_match` | 名称多语言分词（中文 jieba，英文按词） |
| `token_overlap_score` | 名称 token Jaccard 重叠度 |
| `match_torrent_core` | 站点种子与下载器种子匹配：先 mappings，再分词+大小 |
| `format_seeding_time` | 做种秒数格式化为可读字符串 |
| `get_candidate_torrents_for_site` | 按站点地址映射筛选该站点可选的下载器种子 |

### `server/seedinfo_oper.py`
四张表（站点种子主/快照、下载器种子主/快照）的数据库操作与关联业务。

| 方法 | 功能 |
|------|------|
| `init_seedinfo_db` | 建表并做表结构迁移 |
| `_migrate_schema` / `_migrate_table` | 表结构迁移：缺列则加列 |
| `_normalize_downloader_state` | 下载器状态标准化 |
| `batch_save_seeding_from_parser` | 解析结果批量写入站点主表+快照 |
| `list_site_seeds_with_latest_snapshot_by_site` | 按站点查站点种子及最新快照 |
| `delete_seed_info_by_site` | 按站点删除站点种子相关数据 |
| `get_site_seed` | 按站点+种子键查站点种子 |
| `_get_latest_site_snapshot` | 站点种子最新快照 |
| `_get_downloader_seed_by_site_seed_id` | 按 site_seed_id 查关联的下载器种子 |
| `get_downloader_seed_by_hash` | 按 hash 查下载器种子及最新快照 |
| `_get_latest_downloader_snapshot` | 下载器种子最新快照 |
| `upsert_downloader_seed` | 写入/更新下载器种子主表+当日快照 |
| `clear_downloader_seed_site_seed_id` | 取消某站点种子关联（置空 site_seed_id） |
| `list_downloader_seeds_with_latest_snapshot` | 按下载器名列表查所有下载器种子及最新快照 |
| `batch_upsert_downloader_torrents` | 批量写入/更新下载器种子主表+快照 |
| `list_seed_with_latest_snapshot_by_site` | 按站点查站点+下载器联合列表（左连） |
| `get_seed_with_latest_snapshot` | 按站点+种子键查一条站点+下载器四元组 |
| `save_seed_info` | 写站点主表/快照、下载器主表/快照并设关联 |
| `remove_seed_info` | 取消关联（清空下载器种子的 site_seed_id） |
| `save_torrent_mapping` | 封装：补全 sd/dd、seed_attr 后调用 save_seed_info |
| `list_all_mappings` | 返回 站点种子→下载器 hash 的映射表 |
| `apply_downloader_to_row` | 用下载器数据填充展示行 downloader_* 字段 |

### `server/downloader_fetcher.py`
从 qBittorrent 拉取种子列表。

| 方法 | 功能 |
|------|------|
| `get_qb_instance` | 获取 qBittorrent 下载器实例 |
| `fetch_downloader_torrents` | 从配置的下载器拉取种子列表 |
| `fetch_downloader_torrents_by_domain` | 拉取后按 tracker 域名分组返回 |

### `server/sync_bonus_data.py`
做种与魔力参数同步：从站点用户数据或页面拉取并写入插件存储。

| 方法 | 功能 |
|------|------|
| `_fetch_page` | 请求页面返回 HTML |
| `sync_from_siteuserdata` | 从 siteuserdata 读 torrent_activity、bonus_params 写入插件 |
| `sync_from_fetch` | 主动拉取 NexusPHP 做种页、解析并写入插件表与 PluginData |

### `server/page_parser.py`
NexusPHP 页面解析：做种列表与魔力参数。

| 方法 | 功能 |
|------|------|
| `_prepare_html_text` | 预处理 HTML 干扰字符 |
| `parse_bonus_params_nexusphp` | 解析 mybonus 页魔力参数（T0/N0/B0/L 等） |
| `parse_torrent_activity_nexusphp` | 解析做种页，返回做种列表及下页地址 |
| `extract_userid_from_index_nexusphp` | 从首页解析 userid |

### `server/models/site_seed.py`
站点种子：主表与快照表。

| 类 | 功能 |
|------|------|
| `SiteSeed` | 站点种子主表 |
| `SiteSeedSnapshot` | 站点种子快照表 |

### `server/models/downloader_seed.py`
下载器种子：主表与快照表。

| 类 | 功能 |
|------|------|
| `DownloaderSeed` | 下载器种子主表（含 site_seed_id 关联） |
| `DownloaderSeedSnapshot` | 下载器种子快照表 |

### `server/models/__init__.py`
从 `site_seed`、`downloader_seed` 导出上述四个模型类。
